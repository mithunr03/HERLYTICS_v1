# HERLYTICS 🌸
### Intelligent Women's Health & Lifestyle Analytics Platform

**HERLYTICS** is a clinical-grade, modern women's wellness and health analytics platform designed to provide proactive health insights, symptom tracking, hormone & lifecycle analytics, and personalized nutrition planning.

---

## ✨ Features

- **📊 Comprehensive Health Assessment**:
  - Interactive multi-step clinical assessment (demographics, cycle symptoms, reproductive history, metabolic markers, lifestyle factors).
  - Risk prediction scoring for conditions like PCOS, Endometriosis, Thyroid disorders, and Anemia.
- **🥗 Precision Diet & Nutrition Planner**:
  - Tailored nutritional guidelines with macronutrient breakdown based on individual biomarkers.
  - Curated superfoods, foods to moderate, and custom recipe suggestions.
- **📈 Lifestyle & Vitality Tracker**:
  - Daily sleep, water intake, physical activity, and stress tracking.
  - Cycle tracking and symptom correlation.
- **📋 Clinical Reports**:
  - Print & export-friendly summaries for clinical consultations with gynecologists and endocrinologists.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS, PostCSS, Lucide React Icons
- **Build Tooling**: Vite
- **Linting & Code Quality**: Oxlint

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/mithunr03/HERLYTICS_v1.git
cd HERLYTICS_v1

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Build for Production

```bash
npm run build
```
